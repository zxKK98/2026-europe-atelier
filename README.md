# The Autumn Atelier

> 2026 西班牙 × 法国 · 11 天艺术慢旅行手册（马德里 → 巴塞 → 尼斯 → 巴黎）
> Living Europe, Not Visiting Europe.

KK 的私人电子旅行路书。基于 KK Excel《法西 11 日精细化 · 卢浮宫减负版》与 OUIGO 车票、Airbnb 真实订单，一票一晚都有据可查。

## 特性

- Kinfolk / Monocle 风格排版：Fraunces + Inter + Space Grotesk
- 秋日暖赭主题色 · 亮/暗模式记忆
- 11 天完整逐日行程 · Leaflet 内嵌动线 · Vlog 分镜清单
- Experience Collection · Hidden Cafés · Design Guide · Golf · Fashion Week · Mercè · Art Calendar · Packing List
- Creative Missions：每天一个不占时间的小任务
- 秋日粒子背景（Canvas）· 磁性按钮 · 光标混色跟随

## 本地预览

```bash
cd autumn-atelier
python3 -m http.server 5173
# 打开 http://localhost:5173
```

## 部署到 GitHub Pages

将本目录作为一个仓库根目录推送到 GitHub，Settings → Pages → 选择 `main` 分支 `/` 目录即可。
